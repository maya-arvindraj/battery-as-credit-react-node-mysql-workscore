Create a modern, professional fintech web application called “Battery-as-Credit” for Zypp Electric.

The core concept is:
“Turn Gig Work Into Creditworthiness.”
The platform uses a rider’s Zypp work history, earnings, delivery consistency, and payment history to generate a WorkScore that can help them qualify for EV financing.

The main journey is:
KYC & Consent → WorkScore → EV Financing → Earn & Repay → Own the EV

Design this as a polished, realistic website prototype suitable for a college innovation/startup pitch. It should look like a real fintech product, not a generic template.

DESIGN STYLE

Clean, modern fintech UI
Professional but friendly
Minimal and spacious layout
White/light background with dark text
Use Zypp-inspired green as the primary accent
Use dark navy/charcoal for headings and navigation
Use light green backgrounds for positive/eligible states
Rounded cards and buttons
Subtle shadows and borders
Clear visual hierarchy
Modern sans-serif typography
Use simple line icons
Use charts, progress bars, badges and cards where appropriate
Responsive desktop-first design
Keep the interface accessible and easy for gig workers to understand
Avoid excessive gradients, unnecessary animations, and clutter

IMPORTANT

Do not make this look like a banking website overloaded with financial terminology.

The main idea should be immediately understandable:

Earn → Build WorkScore → Get EV → Repay → Own

The interface should communicate trust, accessibility, EV mobility, financial inclusion and progress.

Create all screens in one organized Figma file with clear page/frame names and consistent design components.
